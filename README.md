# Sistema Escolar - Django

Sistema web desarrollado con Python y Django para la gestión académica de instituciones educativas.

## 🚀 Funcionalidades principales

* Gestión de escuelas
* Gestión de cursos
* Gestión de alumnos
* Registro de asistencias
* Registro de observaciones
* Historial de observaciones por alumno
* Consultas y filtros de asistencias
* Consultas y filtros de observaciones
* Panel administrativo de Django
* Deploy online con Render

---

## 🛠️ Tecnologías utilizadas

* Python 3
* Django 5
* SQLite3
* Bootstrap 5
* HTML5
* CSS3
* Git & GitHub
* Render

---

## 📚 Módulos del sistema

### ✅ Asistencias

Permite registrar la asistencia de alumnos por curso y fecha.

### ✅ Observaciones

Permite agregar observaciones académicas o disciplinarias a cada alumno.

### ✅ Consultas

Incluye filtros por:

* curso
* alumno
* asistencias
* observaciones

## ⚙️ Instalación local

Clonar repositorio:

```bash
git clone https://github.com/ivanng01/sistema-escolar.git
```

Crear entorno virtual:

```bash
python -m venv myvenv
```

Activar entorno virtual:

### Windows

```bash
myvenv\Scripts\activate
```

Instalar dependencias:

```bash
pip install -r requirements.txt
```

Aplicar migraciones:

```bash
python manage.py migrate
```

Ejecutar servidor:

```bash
python manage.py runserver
```
